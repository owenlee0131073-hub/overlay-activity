# Overlay Activity

기본 디스플레이 오른쪽 위에 CPU·GPU·RAM 사용률과 화면 FPS를 표시하는 macOS 메뉴 막대 앱입니다. 사용률은 평소 2초마다, FPS 측정을 켜면 1초마다 갱신됩니다. 232 × 46pt 오버레이는 클릭을 아래 창으로 통과시킵니다. 메뉴 막대의 계기판 아이콘에서 표시 여부, 배경 투명도, FPS 측정을 바꾸거나 앱을 종료할 수 있습니다.

**배경 투명도**는 0%에서 100%까지 25% 단위로 조절합니다. 기본값은 25%이고, 100%에서는 글자만 보입니다. 선택한 값은 다음 실행에도 유지됩니다.

## 실행

macOS 13 이상에서 실행됩니다. GitHub Releases에서 빌드된 앱을 받을 수 있습니다. 릴리스 앱은 개발자 인증서 서명과 공증 없이 배포되므로 macOS가 실행을 제한하면 소스에서 빌드할 수 있습니다.

소스에서 빌드하려면 Swift 6이 포함된 Xcode 또는 Command Line Tools를 설치하고 아래 명령을 실행하세요.

```bash
./build.sh
open 'dist/Overlay Activity.app'
```

자동 실행을 쓰려면 앱을 **응용 프로그램** 폴더에 옮겨 실행한 뒤 계기판 메뉴의 **로그인 시 실행**을 켜세요. 이후 macOS에 로그인할 때 오버레이가 열립니다. macOS에서 승인을 요청하면 **시스템 설정 → 일반 → 로그인 항목 및 확장 프로그램**에서 허용하세요.

## 측정값

- CPU는 전체 코어의 사용률입니다.
- GPU는 드라이버가 공개하는 전체 GPU 사용률입니다. 해당 값이 없는 기기에서는 `–`로 표시합니다.
- RAM은 파일 캐시를 제외한 물리 메모리 사용률입니다.
- FPS는 화면에 새로 표시된 프레임 수입니다. 정적인 화면에서는 값이 낮아지며, 개별 앱이나 게임의 렌더링 FPS와는 다를 수 있습니다.

CPU·GPU·RAM은 75% 미만에서 흰색, 75–89%에서 노란색, 90% 이상에서 빨간색으로 표시됩니다.

FPS를 보려면 계기판 메뉴의 **FPS 측정 켜기**를 선택하고, 시스템 설정의 **개인정보 보호 및 보안 → 화면 및 시스템 오디오 기록**에서 Overlay Activity를 허용하세요. macOS가 요청하면 앱을 종료하고 다시 실행하세요. 앱은 프레임 상태만 세며 화면 이미지와 오디오를 저장하거나 전송하지 않습니다. 오버레이를 숨기거나 화면이 잠들면 측정이 멈춥니다.
